# АССА — сайт Академии Сферического Сознания Альва

Статический многостраничный сайт: HTML + CSS + JS, без сборки и без сервера.
Открывается двойным кликом по `index.html`, на хостинг отдается папка целиком.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная: обзор Академии, направления обучения, учитель, марафоны, клуб, контакты |
| `about.html` | Об Академии: история с 1983 года, концепция, чему можно научиться, как проходит обучение |

| `practice.html` | Практика: индивидуальная работа (условия и стоимость) и работа в Круге |

## Подключение к Скул Мастеру

Все ссылки, которые должны вести в LMS, собраны в одном файле — `js/config.js`.
HTML править не нужно.

```js
lms: {
  base:    'https://ВАША-ШКОЛА.skoolmaster.ru',   // адрес школы в Скул Мастере
  cabinet: '/login',      // кнопка «ЛИЧНЫЙ КАБИНЕТ» (шапка, подвал, контакты)
  start:   '/register',   // кнопка «НАЧАТЬ ОБУЧЕНИЕ»
  courses: {
    school9:   '/courses/school-9',   // кнопка «Записаться в школу» на school.html
    firststep: '/courses/first-step', // «Группа программы» на first-step.html
    bank:      '/courses/bank',       // «Получить доступ» к Банку тренировок
    circle:    '/courses/circle',     // «Подробнее» о Круге на practice.html
    eniyoga:   '/courses/eniyoga'     // «Группа Энийоги» на yoga.html
  }
}
```

Можно указывать как относительные пути (подставится `base`), так и полные `https://...`.
Пока ссылка на курс пустая, кнопка ведет на текущую Telegram-группу (атрибут `data-fallback`).

В HTML кнопки помечены атрибутами:
- `data-lms="cabinet"` — вход в личный кабинет;
- `data-lms="start"` — регистрация / начать обучение;
- `data-lms-course="school9"` и т.д. — конкретный курс.

Если Скул Мастер дает виджет формы записи (HTML-код `<script>`/`<iframe>`),
его удобно вставить в блок `<section ... id="start">` на `index.html`
(раздел «ЧЕМУ МОЖНО НАУЧИТЬСЯ В АКАДЕМИИ») — на него ведут все кнопки «Начать обучение».

Телефоны и ссылки соцсетей тоже меняются в `js/config.js` (`phones`, `socials`).
Если у соцсети пустая ссылка — ее иконка скрывается.

## Картинки

- Все картинки на страницах — WebP. Исключения — `images/og.jpg` (превью ссылки,
  `og:image`, 1200×630, полный URL) и `images/logo.png` (favicon): мессенджеры
  и Safari не везде понимают WebP в этих местах;
- `images/header.webp` — арт шапки (и перевернутый — в завершающей полосе);
- `images/logo.webp` — герб; `images/teacher.webp` — фото И. В. Савельевой;
- иллюстрации разделов, галерея Школы, обложки марафонов подключены по прямым
  ссылкам с telegra.ph. Чтобы сайт не зависел от telegra.ph, один раз запустите
  `sh download-images.sh` (нужен `curl`) — картинки скачаются в `images/tg/`,
  а ссылки в HTML заменятся на локальные.

## Шрифты и анимация

- Текст — Candara, заголовки — Century Gothic (`fonts/`, подключены через `@font-face`),
  запасной вариант — Jost с Google Fonts.
- Шапка: фон + частицы, звезды и золотые волны на `<canvas>` (`js/main.js`).
- Волны между секциями — SVG с бесшовным сдвигом; послойное появление при прокрутке;
  круги следуют за курсором. При `prefers-reduced-motion` анимация отключается.

## Как править содержимое

Страницы — обычный HTML. Основные блоки:
- `<h2 class="pill">` — синяя плашка-заголовок;
- `.split` + `.circle` — «круг + текст»;
- `.grid` + `.card` — карточки; `.card--glass` — на синем фоне;
- `.price-list` / `.price-row` — условия и стоимость;
- `.person-card` — карточка сотрудника (вместо инициалов в `.avatar` можно поставить `<img>`);
- `.link-list` — списки ссылок с иконками.

Меню (выпадающее по кнопке «МЕНЮ») и подвал одинаковы на всех страницах —
при добавлении новой страницы скопируйте их из любой существующей.
