# АССА — сайт Академии Сферического Сознания Альва

Статический многостраничный сайт: HTML + CSS + JS, без сборки и без сервера.
Открывается двойным кликом по `index.html`, на хостинг отдается папка целиком.

## Подключение к Скул Мастеру

School Master на `https://academy.alva.club` — бэкенд сайта: личный кабинет,
обучение, заказы и доступы. Публичный сайт находится на `https://alva.club`.

Все ссылки, которые должны вести в LMS, собраны в одном файле — `js/config.js`.
HTML править не нужно.

```js
lms: {
  base:    'https://ВАША-ШКОЛА.skoolmaster.ru',   // адрес школы в Скул Мастере
  cabinet: '/login',      // кнопка «ЛИЧНЫЙ КАБИНЕТ» (шапка, подвал, контакты)
  start:   '/register',   // кнопка «НАЧАТЬ ОБУЧЕНИЕ»
  courses: {
    school9:   '/courses/school-9',   // кнопка «Записаться в школу» на school.html
    firststep: '/courses/first-step', // «Группа программы» на first-step.html
    bank:      '/courses/bank',       // «Получить доступ» к Банку тренировок
    circle:    '/courses/circle',     // «Подробнее» о Круге на practice.html
    eniyoga:   '/courses/eniyoga'     // «Группа Энийоги» на yoga.html
  }
}
```

Можно указывать как относительные пути (подставится `base`), так и полные `https://...`.
Пока ссылка на курс пустая, кнопка ведет на текущую Telegram-группу (атрибут `data-fallback`).

В HTML кнопки помечены атрибутами:
- `data-lms="cabinet"` — вход в личный кабинет;
- `data-lms="start"` — регистрация / начать обучение;
- `data-lms-course="school9"` и т.д. — конкретный курс.

Если Скул Мастер дает виджет формы записи (HTML-код `<script>`/`<iframe>`),
его удобно вставить в блок `<section ... id="start">` на `index.html`
(раздел «ЧЕМУ МОЖНО НАУЧИТЬСЯ В АКАДЕМИИ») — на него ведут все кнопки «Начать обучение».

Телефоны и ссылки соцсетей тоже меняются в `js/config.js` (`phones`, `socials`).
Если у соцсети пустая ссылка — ее иконка скрывается.

## Картинки

- Все картинки на страницах — WebP. Исключения — `images/og.jpg` (превью ссылки,
  `og:image`, 1200×630, полный URL) и `favicon.ico`: мессенджеры
  и Safari не везде понимают WebP в этих местах;
- Единый favicon сайта и School Master — `landing/images/brand/favicon.ico`.
  Его копия `landing/favicon.ico` подключена на всех публичных страницах;
  тот же файл загружается в School Master: Настройки → Основные настройки → Favicon.
  При замене обновляйте версию в ссылках страниц для сброса кеша браузера;
- `images/header.webp` — арт шапки (и перевернутый — в завершающей полосе);
- `images/logo.webp` — герб; `images/teacher.webp` — фото И. В. Савельевой;
- иллюстрации разделов, галерея Школы, обложки марафонов подключены по прямым
  ссылкам с telegra.ph. Чтобы сайт не зависел от telegra.ph, один раз запустите
  `sh download-images.sh` (нужен `curl`) — картинки скачаются в `images/tg/`,
  а ссылки в HTML заменятся на локальные.

## Шрифты и анимация

- Текст — Candara, заголовки — Century Gothic (`fonts/`, подключены через `@font-face`),
  запасной вариант — Jost с Google Fonts.
- Шапка: фон + частицы, звезды и золотые волны на `<canvas>` (`js/main.js`).
- Волны между секциями — SVG с бесшовным сдвигом; послойное появление при прокрутке;
  круги следуют за курсором. При `prefers-reduced-motion` анимация отключается.

## Как править содержимое

Страницы — обычный HTML. Основные блоки:
- `<h2 class="pill">` — синяя плашка-заголовок;
- `.split` + `.circle` — «круг + текст»;
- `.grid` + `.card` — карточки; `.card--glass` — на синем фоне;
- `.price-list` / `.price-row` — условия и стоимость;
- `.person-card` — карточка сотрудника (вместо инициалов в `.avatar` можно поставить `<img>`);
- `.link-list` — списки ссылок с иконками.

Меню (выпадающее по кнопке «МЕНЮ») и подвал одинаковы на всех страницах —
при добавлении новой страницы скопируйте их из любой существующей.


## Кнопки заказа, оплаты и бронирования

Кнопки на страницах помечены `data-offer="ключ"`. Каталог из 37 вариантов находится
в `landing/js/config.js`, раздел `offers`. Для подключения оплаты достаточно
заполнить `paymentUrl` выбранного варианта. Для календаря или формы бронирования
заполните `bookingUrl`. Принимаются абсолютные HTTPS-ссылки.

Например, в `offers["firststep.standard"]`:

```js
paymentUrl: 'https://ВАШ-ПЛАТЕЖНЫЙ-СЕРВИС/ССЫЛКА-НА-ТОВАР',
bookingUrl: 'https://ВАША-ФОРМА-ЗАПИСИ/ССЫЛКА'
```

Пока поля пустые, окно заказа показывает товар, цену и условия, затем открывает
Telegram куратора с подготовленным текстом. Сообщение отправляет сам посетитель.
Даты и участие подтверждает куратор; сайт не создает подтвержденную бронь.
Личные данные на сайте не собираются. Подключение ссылок не создает платежи
самостоятельно: товар, сумму, доступы и статус оплаты настраивают в платежном
сервисе / School Master.

Ключи каталога:

| Раздел | Ключи |
|---|---|
| Школа | `school.step1` … `school.step9`, `school.step1Pair` … `school.step9Pair` |
| Пакеты и год | `school.steps1to3`, `school.steps4to6`, `school.steps7to9`, `school.annual` |
| Заявка в Школу | `school.enroll` |
| Первый шаг | `firststep.standard`, `firststep.early`, `firststep.step1`, `firststep.steps1to3` |
| Банк тренировок | `bank.access` |
| Консультации | `consultation.first`, `consultation.student`, `consultation.family`, `consultation.master`, `consultation.teacher` |
| Бесплатная первичная работа | `consultation.support` — только запись (`bookingOnly: true`) |
| Круги | `circle.session`, `circle.selfknowledge` |
| Энийога | `eniyoga.class` |

`contact` задает куратора конкретного товара; `orders.contact` — общий резервный
контакт. `price` и `conditions` — сведения в окне заказа: при изменении тарифа
обновите также цену в HTML страницы и соответствующий товар платежного сервиса.
Прежние `schoolPayments.step1` и другие ключи Школы поддерживаются как резервные
платежные ссылки, но новый `offers["school.step1"].paymentUrl` имеет приоритет.
Не загружайте `school-payment.js` вместе с общим `orders.js`.

## Расписание и события

`schedule.html` объединяет публичный календарь и личную запись; в каталоге обучения есть
блок трёх ближайших событий. Источник — календарь School Master
`https://academy.alva.club/event-calendar`. Он включён, событий пока нет.
Поскольку School Master запрещает iframe с другого домена, публичные события
передаются через анонимный JSON-снимок `landing/data/calendar.json`.

Синхронизация подготовлена в `scripts/sync-public-calendar.py`: без admin cookie
и без токена MCP, только события, видимые неавторизованному посетителю.
При ошибке прежний файл сохраняется. После публикации страницы можно установить
синхронизацию раз в пять минут командой `sh scripts/install-calendar-sync.sh`.
Обновление публичного календаря установлено 19.10.2026: раз в пять минут.

В `ASSA_CONFIG.schedule.specialists` задаются реальные страницы слотов
специалистов (`bookingUrl`). Порядок для платных консультаций:
**выбор времени → оплата → подтверждение**, которое выполняет School Master.
Пока слоты и платежи не настроены, используется согласование в Telegram;
сайт не объявляет такую заявку подтверждённой бронью. Подробное состояние,
ограничения и порядок запуска — в
`materials/school-master/calendar-booking-plan.md`.
