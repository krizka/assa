## Размещение на сайте

- `schedule.html`: общий календарь, фильтры направлений, отдельная личная запись.
- Главное меню и подвал всех десяти основных страниц: «Расписание и события».
- Главная: компактный блок ближайших трёх открытых событий перед каталогом программ.
- «Практика»: ссылка на специалистов рядом с условиями и тарифами.
- «Команда»: вход в запись; карточки специалистов в расписании используют существующие фото и роли.
- У Учителя отдельно сохраняется условие работы с учениками по необходимости; новичкам предлагается запись к куратору.

## Публичные события: один источник

События создаются в School Master. Открытые показываются на alva.club через `data/calendar.json`.
`sync-public-calendar.py` запрашивает только анонимную публичную страницу: без cookie,
токена MCP и авторизации. Из ответа извлекается JSON без исполнения JavaScript.
Исключаются события открытия уроков, выключенные события и записи с ограничениями
по группам/подпискам. Описание преобразуется в обычный текст. Частные записи и
Zoom-ссылки закрытых групп не выгружаются из кабинета.

Сейчас публичных событий нет. В репозитории сохранён проверенный пустой снимок;
даты не выдумывались. Категория определяется по названию тега/события; неизвестные
теги остаются видимыми в «Все».

Для общего обзора платных занятий публикуйте открытый анонс с названием, датой и
ссылкой на запись. Ссылки Zoom, материалы учеников и персональные консультации
остаются в закрытом календаре школы. Личные записи не входят в публичную афишу.

После публикации сайта администратор устанавливает синхронизацию:

```sh
sh scripts/install-calendar-sync.sh
```

Скрипт копируется в `/home/alva/site-tools/`, вне web root. В пользовательский cron
добавляется ровно одна задача с маркером `ALVA_PUBLIC_CALENDAR` раз в 5 минут,
остальные задачи сохраняются. Задание читает только общедоступный календарь и
записывает публичный JSON. При сетевой ошибке или изменении формата прежний файл
сохраняется. Интерфейс предупреждает, если снимок старше суток, и даёт ссылку на
школьный календарь. Обновление установлено 19.10.2026; проверено одно задание cron.
При последующих публикациях не затирать актуальный серверный JSON старой локальной
копией; синхронизировать его заново после публикации.

## Запись: согласованный порядок

Пользователь выбрал: специалист и время → оплата → подтверждение записи.
Сайт не подтверждает оплату по параметру URL, localStorage или нажатию кнопки.
Удержание слота, занятость, освобождение при неоплате, проверка оплаты и
подтверждение должны выполняться штатным модулем School Master.

В `config.js → schedule.specialists` подготовлены карточки и поля `bookingUrl`.
Они пока пусты. Пока нет реальных часов, кнопка отправляет запрос на согласование
времени выбранному специалисту. В модальном окне можно изменить куратора; Учитель
не предлагается для первичной консультации новичка. Бесплатная первичная работа
не получает кнопку оплаты.

## Что нужно для запуска живой записи

1. Реальные часы приёма и исключения каждого специалиста, длительность слотов и буфер между встречами. Фиксировать время в МСК; дать пользователю понятный часовой пояс.
2. Назначить в School Master только согласованных консультантов. Не включать доступ всем авторам автоматически.
3. Настроить реальные цены и типы консультаций: 7 500 ₽ для новичков; 5 000 ₽ для учеников и семейных консультаций; 10 000 ₽ — работа с Учителем по условиям Академии. Мастерский формат согласовывается; бесплатная первичная работа остаётся бесплатной. Значение 1 000 ₽ из настроек модуля использовать нельзя.
4. Настроить штатную задачу CRON модуля (путь показан в настройках) через администратора сервера школы. На сервере alva.club её не запускать — это другой контур.
5. Подключить оплату консультационных продуктов и проверить в тестовом режиме: слот до оплаты; успешная оплата и подтверждение; отказ оплаты; истечение удержания; одновременный выбор одного времени двумя клиентами. Не делать реальные списания для теста.
6. Проверить перенос, отмену, часовой пояс, уведомления клиента и специалиста. Реальные письма и напоминания включать только для согласованных встреч.
7. Получить фактические ссылки на страницы слотов специалистов, заполнить `bookingUrl`, активировать модуль после проверки. Не подставлять выдуманный URL.
